# PixelNest — Frontend Template

A responsive **HTML/CSS multi-section website template** — featuring a landing page, services, portfolio gallery, about section, and contact form, styled with a modern design.

## What it does

A fully static front-end template named PixelNest, built from scratch with HTML and CSS. Designed as a creative agency or portfolio website template with multiple content sections.

## Live Demo

🌐 [ahmedelneziliiy.github.io/PixelNest](https://ahmedelneziliiy.github.io/PixelNest/)

## Tech Stack

- **HTML5**
- **CSS3** — modular stylesheets per section
- **Font Awesome** — icons

## Sections

- Landing / Hero
- Services
- Portfolio
- About
- Contact

## Getting Started

Open `index.html` directly in a browser — no build step required.
