# PixelNest — Frontend Template

A responsive **HTML/CSS multi-section website template** featuring a landing page, services, portfolio gallery, about section, and contact form.

## Live Demo

🌐 [ahmedelneziliiy.github.io/PixelNest](https://ahmedelneziliiy.github.io/PixelNest/)

## Tech Stack

- **HTML5** / **CSS3** — modular stylesheets per section
- **Font Awesome** — icons

## Sections

- Landing / Hero, Services, Portfolio, About, Contact

## Getting Started

Open `index.html` in a browser — no build step required.
